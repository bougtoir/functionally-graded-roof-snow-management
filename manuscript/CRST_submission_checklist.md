# CRST submission checklist

- [x] Editable single-column Word manuscript
- [x] Abstract no longer than 250 words
- [x] Six keywords
- [x] Separate highlights file with 3-5 bullets, each <=85 characters
- [x] Continuous line numbering requested in DOCX XML
- [x] Editable manuscript tables
- [x] Figures supplied separately as EPS, PDF, SVG, TIFF, and PNG
- [x] Data/code availability and generative-AI statements
- [ ] Author affiliation and postal address confirmed
- [ ] Funding and competing-interest declarations confirmed
- [ ] CRediT roles confirmed by the author
- [ ] Originality and author-approval statement confirmed
- [ ] Current Guide for Authors manually rechecked before submission (archival acquisition returned HTTP 403)
