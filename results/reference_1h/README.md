# Historical 1-hour reference

This directory preserves the pre-revision 1-hour production outputs and audits.
They are historical comparison evidence, not the canonical current results.

The current production analysis uses a 0.5-hour timestep. The audit subdirectory
contains the prior final-revision narratives before they were regenerated from
the 0.5-hour outputs. `SHA256SUMS.txt` covers every retained file in this
directory other than the checksum list itself.
